# Codex 小龙桌宠

当前版本：0.6.0。Windows 本地悬浮桌宠，陪伴使用 Codex，并提示工作结束和额度变化。

新增休息、唤醒、走动和投喂：右键选择“休息一会儿”，小龙会蜷身闭眼、保持轻微呼吸；点击她或选择“叫醒小龙”即可缓缓起身。“走一小段”会在当前屏幕内移动一小段距离，拖动可随时打断；“喂一块点心”会捧起饼干、吃掉再收手。睡着时选择投喂会先醒来再吃，新工作开始也会唤醒。休息不会自动触发；安静陪伴仍接受手动互动，减少动画时只提供文字回应。再次启动程序或使用托盘“显示并叫醒小龙”也能唤回桌宠。

本版重做动作衔接：待机、工作、摸头、喝茶、伸展、拿起、落地和庆祝共用同一套分层角色，动作中断从当前姿势柔和接续。增加点头打招呼、歪头跟随、闭眼蹭蹭摆尾和蓄力跳跃。默认 50% 小尺寸，右键“调整大小”可选 40%、50%、60% 等档位；升级保留已有设置，需要时可手动选 50%。

待机时有自然呼吸、眨眼、发尾和翼尾微动；“一起喝茶”播放 10 秒的拿杯、举杯、喝茶、放杯和收杯。伸展和庆祝使用连续的肩、肘、腕运动；拖动时轻轻晃动，落地有缓冲。“日常小动作”可暂停自动动作和待机微动；安静陪伴暂停自动动作，仍可手动互动；减少动画保留静态状态和文字回应。

## 使用

0.6.0 提供已编译的 `codex-dragon-pet-0.6.0.zip`：解压到长期保留的位置，双击 `start.cmd`，或者直接运行 `bin/CodexDragonPet.exe`。桌宠默认出现在屏幕右下角，置顶显示。已经运行时再次启动会把她从托盘唤回。请先在这台电脑安装并登录 Codex。不要把 GitHub 自动生成的 Source code 压缩包当作免编译运行包。

从旧安装版升级：把 ZIP 解压到一个新文件夹，再双击 `update.cmd`。更新程序从现有自动联动快捷方式寻找安装目录，找不到时检查当前用户的默认安装目录；备份旧程序后替换运行文件、校验哈希并重新启动。用户设置和原自动联动入口保留。自定义便携目录可运行 `powershell -NoProfile -File ./scripts/Update-Installed.ps1 -TargetDirectory "旧目录"`。备份保存在原安装目录的 `backup` 中。0.6.0 提供 ZIP，未附 Setup.exe。

校验、无人值守安装、升级和卸载说明见 [安装说明](docs/INSTALLATION.md)。

如果 GitHub 匿名 API 提示限流，直接使用本页安装包链接或 [最新发布页面](https://github.com/liuliuliu-a11y/codex-dragon-pet/releases/latest) 下载即可。公开安装包不要求登录 GitHub，也不需要申请或提供 GitHub 令牌。

需要同时打开 Codex 时，双击 `start-with-codex.cmd`；它会启动或复用已打开的 Codex 桌面应用，并启动小龙。这是联合启动入口，不会修改系统开机启动项或添加常驻监控程序。`start.cmd` 仍然只启动小龙。

要让原来的 Codex 图标也能自动带起小龙，执行 `./scripts/Install.ps1`。它会为当前用户安装一个轻量联动程序并加入用户登录启动项；以后打开或重新激活新开的 Codex 桌面宿主窗口时，会启动小龙。联动程序只观察进程名和窗口激活事件，不读取窗口文本、键盘或聊天内容，也不做循环轮询。Codex 桌面宿主可能显示为 ChatGPT。

只想手动启动可用 `./scripts/Install.ps1 -NoAutoLink`；关闭已安装的自动联动用 `./scripts/Disable-CodexLink.ps1`，不会删除源码、桌宠设置或聊天。开启自动联动后请保留安装目录。

## 简介与 AI 安装指令（可直接转发）

把下面这段发给能操作你电脑的 AI（如 Codex）：

使用前请在本机安装并登录 Codex；需要 .NET Framework 4.8。没有本机操作能力的 AI 也可以按文档指导你手动安装。

开发者也可以从源码安装：

```powershell
git clone https://github.com/liuliuliu-a11y/codex-dragon-pet.git
cd codex-dragon-pet
powershell -NoProfile -ExecutionPolicy Bypass -File ./scripts/Install.ps1
```

上述执行策略只对本次安装进程生效。请先在 Codex 桌面应用中正常登录；保持项目目录不被移动或删除，登录启动项才能继续找到联动程序。

- **拖动角色**：移动位置，退出时自动保存。
- **单击角色**：闭眼蹭蹭、摆尾、爱心和简短回应。
- **右键 → 点头打招呼 / 开心跳一下**：播放点头回应或蓄力跳跃。
- **双击角色 / 单击底部状态条**：打开工作与额度面板。
- **右键角色**：切换气泡、提示音、置顶、大小，或收起到托盘、退出。
- **鼠标穿透**：在右键菜单或工作面板中开启；在系统托盘菜单取消勾选即可恢复互动。
- **安静陪伴**：保留状态和重要气泡，关闭声音与托盘弹窗；普通进展气泡自动收起。
- **减少动画**：停止浮动与互动动画，继续保留状态变化及提醒。
- **双击托盘图标**：重新显示小龙和工作面板。

系统托盘和程序使用同一套小龙头像图标，包含 16–64 像素尺寸；源图与图标文件见 `assets/tray-icon.png` 和 `assets/tray.ico`。

## 已实现

角色在工作、思考、等待和额度偏低时用同一形象的头部姿态与气泡表达状态，动作播放不再切换整身姿态图。袖手与茶杯由肩、肘、腕锚点带动；伸展、拿起、落地和庆祝也使用连续姿态。普通动作有起势与收势，打断动作时从当前可见姿态进行约 0.22 秒过渡。喝茶结束恢复当时的工作状态；工作结束可打断喝茶，拖动中的结束庆祝等待落地后播放。隐藏窗口取消动作并停止动画计时器，再显示时不重播旧动作。工作进展气泡显示 Codex 公开的 commentary 消息与工具类别；碎碎念明确标注为角色台词。

分层素材沿用原待机图的脸部、龙角、发饰及大部分身体像素；被遮挡衣服、袖手、茶杯和闭眼纹理由内置图像工具补绘，仍有二维纸偶感。运行使用本机 WPF，无需视频服务、大模型或新增后台服务。动画按连续时间计算，不保证每台电脑的物理屏幕刷新率。

单击摸头会显示简短回应，姿态切换有柔和过渡。桌面气泡只显示一句话状态，例如“正在阅读文件”“正在检查和测试”；完整公开进展和结果摘要保留在工作面板中。普通气泡过一段时间自动收起，完成时重新显示简短提醒。面板包含最近结束的本机聊天入口。

监听本机 Codex 聊天记录，约每秒读取增量。最终回复写入后先显示“正在输出结果”，收到 `task_complete` 后显示“正在收尾，确认结果”；最终回复与结束事件均已读到、记录完整且连续 3 秒没有新写入，才显示结束气泡、庆祝和可关闭的声音提醒。续接任务、继续调用工具或继续汇报进展会取消待确认提醒。自动跟随时，其他聊天结束不会盖住当前仍在工作的聊天。启动时不重播历史提醒，同一轮不会重复提醒；中断与失败单独显示。此确认基于本机记录，不能观测 Codex 界面逐字渲染是否已完成，也不判断业务结果是否成功。

额度通过本机 Codex 的 `app-server`，调用官方 `account/rateLimits/read` 读取，通常每 60 秒刷新；聊天日志已有新鲜额度时会复用记录，避免重复启动查询进程。支持多个额度桶与实际窗口时长，显示已用比例、剩余比例、重置时间、数据时间；没有数据时显示不可用。80% 和 95% 阈值各提醒一次。过期或较旧数据会标记，等待刷新。

工作面板可自动跟随正在工作的最近聊天，也可固定到一个本机聊天。并行子代理不会单独弹完成提醒。仅监测这台电脑保存的本地聊天，尚不覆盖只在云端运行的任务。

## 数据与设置

- 读取 `$CODEX_HOME/sessions`，未设置时读取 `%USERPROFILE%/.codex/sessions`；不修改聊天记录。
- 设置保存到 `%LOCALAPPDATA%/CodexDragonPet/settings.json`。
- 额度子进程只执行初始化与账户额度读取，不发起模型推理，不额外消耗聊天 token。认证由现有 Codex 程序处理。
- 工作状态采用公开进展；角色台词单独标识。
- 程序不上传聊天内容，也没有开放本地网络端口。额度刷新需要 Codex 正常登录和联网。
- 当前使用本地 JSONL 事件作为桌面应用的旁路状态来源，日志格式未来变化时可能需要更新适配。读取中断时保留最近数据及更新时间。

## 资源占用与限制

连续分层动画按实际经过时间计算，更新频率受 WPF 调度与硬件影响。安静模式暂停自动动作，隐藏时停止动画。已复用日志读取缓冲区及未变化的额度控件。历史资源测量见 [性能记录](docs/PERFORMANCE.md)，不作为本版性能承诺。

状态适配的是本机 Codex JSONL 日志，格式变化时可能需要更新；仅云端运行的任务不在监测范围内。工作状态来自公开进展与工具类别，角色台词为预设回应。额度是账户窗口的已用比例，不是费用估算。系统通知是否出现、提示音是否可闻，也受 Windows 通知与声音设置影响。

上传排除 `bin/`、`verification/`、`.context/`、依赖目录、缓存、日志和本机设置；诊断记录可能包含聊天标识或公开进展，保留在本地，不上传仓库。
