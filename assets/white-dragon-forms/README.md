# 六套白龙形态源图

以既有白龙和用户提供的进阶形态图为参考，由内置图像生成工具制作。共同特征为银白长发、紫瞳、象牙色龙角、白玫瑰发饰、白／淡紫服装和翼尾。

六张透明图为 `low.png`、`medium.png`、`high.png`、`xhigh.png`、`ultra.png`、`astra.png`。每张为 4×4 图集，按阅读顺序包含：站立、闭眼、摸头回应、挥手、收手、捧杯、喝茶、拿点心、吃完点心、两个步态、提起、落地、坐下休息、蜷身睡眠、抱电脑。

生成约定：同一形态内保持身份、服装、画风和比例；每个姿态完整位于单格，保留透明间隔，不包含文字或界面。高阶形态增加展开的翼、光环及盘绕神龙。

`scripts/Build-SmoothForms.py` 进行主体注册、比例和脚底对齐，生成双向运动补帧与闭环局部动作，输出六套 `clips.json` 时间线和 PNG。每套映射到现有 33 个原生播放段，左右步态共享帧并镜像播放。

运行时素材由脚本生成并放入发布包，原始图集随源码保存。局部遮挡和姿态差异可能产生轻微插值变形。形态展示属于角色设计，不用于推断模型性能或账户用量。
