# 白龙动作源图

以本项目 `assets/dragon-sprites-clean.png` 的白龙形象为唯一角色参考，由内置 ImageGen 生成。保留银白长发、紫瞳、象牙色龙角、白玫瑰发饰、白色中式服装、淡紫翼尾。

五张原始透明图均为 4×4 格，共 80 个姿态格：

| 图集 | 前八格 | 后八格 |
|---|---|---|
| walk-sleep.png | 向右走路 | 站立到蜷身侧躺 |
| idle-pet.png | 待机呼吸与眨眼 | 摸头反应 |
| lift-wave.png | 被提起 | 挥手庆祝 |
| tea-food.png | 拿杯喝茶与收杯 | 拿点心吃掉与收手 |
| work-think.png | 抱电脑工作 | 思考 |

`scripts/Pack-WhiteDragon.ps1` 调用 C# 导入器，按格提取主体、隔离邻格碎片、保留边缘抗锯齿，将整套姿态用一致比例注册到 500 单位透明画布，并按脚底基准对齐。左右走路使用镜像；开始、循环、结束段复用对应姿态，输出共 142 个播放帧。原始生成图保留在本目录，导入器不重绘角色。

播放采用 VPet-Simulator.Core 1.1.0.72。该资源包只含本项目白龙，VPet 的默认角色素材未用于此包。
