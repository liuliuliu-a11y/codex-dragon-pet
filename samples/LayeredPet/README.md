# 小龙分层动画小样

这是独立预览入口；主桌宠 0.4.0 已共用同一分层动画源码与素材。启动此预览本身不修改桌宠安装，不安装模型、后台服务或启动项。

## 操作

启动 `LayeredDragonPreview.exe` 后，自动播放待机 → 10 秒喝茶 → 待机。

- 待机：回到自然呼吸、眨眼与发尾微动。
- 喝茶：从头播放舒展双手、拿杯、举杯、喝茶、放杯、收杯。
- 暂停：冻结动作；再次点击继续。
- 拆开看看：将左右袖手和杯子分开，保持举杯姿态以观察部件；合起来后继续动作。
- 空格：暂停或继续。Esc：关闭。

## 实现与素材

原图脸、龙角、发饰及身体大部分像素沿用原素材。闭眼纹理、手袖、被手臂遮挡的衣服和茶杯由内置 image_gen 补绘；源图在 `source/`，运行素材与注册说明在项目根目录 `assets/layered/`。原待机脸部区域在资产打包时进行逐字节一致性检查。共用源码在 `src/LayeredDragonRig.cs`，小样构建引用此文件，不维护另一套动作轨迹。

动作使用肩、肘、腕锚点、连续关键帧轨迹和二维纹理网格变形。袖子向下垂落，手掌保持托杯方向。眼睑使用独立纹理，发尾、翼尾和呼吸在原图网格上连续变形。程序不播放一组完整角色姿态图来模拟喝茶。

这是分层小样：袖子、握杯手势和闭眼纹理经过补绘，仍有二维纸偶感；没有模拟真实三维布料或生成电影级逐帧动画。原图保持是以角色身份和主要原始纹理为基准，不表示补绘部件与原图逐像素相同。

## 构建与验证

使用本机 .NET Framework 4.x 和 WPF，无需第三方运行依赖。运行 `build.ps1 -Check` 编译并检查 601 个连续姿态、坐标有效性、肩膀锚点、杯手运动连续性和结束恢复。界面及动作质量另外通过实际窗口录屏检查。

`preview-window.mp4` 是 FFmpeg gdigrab 采集的真实预览窗口，`preview.gif` 是其缩小预览。没有用外部视频模型或补帧模型制作这些文件。
