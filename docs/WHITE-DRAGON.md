# 白龙桌面伙伴 0.8.1

六档形态、连续互动动作与本机 Codex 工作联动，支持可选的小G聊天服务。

## 运行与更新

Windows 10/11 64 位：完整解压 ZIP，双击 `start.cmd`。运行包已包含 .NET 8。

更新旧版：把 ZIP 解压到新文件夹，双击 `update.cmd`。它会备份旧程序、校验更新文件，并保留原设置、额外个人文件和已有的自动联动入口。备份位于原安装目录的 `backup`。回退时退出新版，恢复所需备份中的 `bin`，个人设置继续保留。

`start-with-codex.cmd` 联合打开 Codex 和桌宠；`start-chat.cmd` 打开小G聊天窗。聊天需另行配置兼容的小G服务。服务未运行时，基础桌宠继续显示角色、互动、跟随模型并监测本机 Codex 状态。

## 操作

- 单击角色：摸头或身体互动；按住角色或底部状态条移动：拖动。
- 单击状态条：查看工作状态、公开进展和额度。
- 右键“更多互动”：喝茶、点心、休息、叫醒和走动。
- 右键“陪伴设置”：安静模式、自主走动、气泡、回复动作及本机小G连接。
- 右键“大小与位置”：150–340 像素档位、置顶和位置恢复。
- 收起后从托盘恢复。拖动中遇到任务结束，会先落地再庆祝。

## 模型与形态

在 Codex 中选择模型和思考强度。桌宠读取下一轮实际执行记录后更新外观：`low` 为小白龙，`medium`、`high`、`xhigh` 逐步变化，`ultra` 展翼；Astra 的 `ultra` 使用身后盘绕神龙的形态。`max` 对应 Ultra，未提供强度时使用基础形态。

动作变化区间按约 30 帧/秒生成中间姿态；工作、睡眠和提起后的保持姿态带小幅连续动作。图形采用二维素材与运动插值。

## 小G服务与数据

聊天、记忆、养成与提案通知通过固定的本机地址 `http://127.0.0.1:8766` 连接。运行包提供客户端，兼容服务需另外准备。已有的 `companion-link.json` 属于个人启动配置，更新时保留，不包含在公开包中。设置可在右键“陪伴设置”管理。

公开包不包含个人设置、聊天、账户文件或测试记录。形态切换和动作已有实际窗口渲染检查；拖动控制和提醒已有程序回归。物理鼠标拖拽、多屏与跨 DPI 操作仍需手工验收。

## 角色与第三方组件

角色以本项目既有白龙形象为参考生成，包含银白长发、紫瞳、龙角、白色服装与淡紫翼尾。运行时使用自有白龙素材。
