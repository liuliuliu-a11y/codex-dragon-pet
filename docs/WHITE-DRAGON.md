# 白龙桌面伙伴 0.7.0

保留原有白龙形象，采用 VPet-Simulator.Core 动画内核。银白长发、紫瞳、龙角、白色服装和淡紫翼尾沿用原角色；走路、蜷身睡觉、摸头、提起、挥手、喝茶、吃点心和抱电脑均使用重新制作的动作帧。

## 使用

Windows 10/11 64 位：完整解压 ZIP，双击 `start.cmd`。运行包自带 .NET 8 运行时，首次使用无需另装 SDK。

已安装旧版小龙时，把 ZIP 解压到新文件夹，双击 `update.cmd`。它会备份原程序、更新运行文件并校验，原来的设置与 Codex 自动联动入口保留。旧程序备份位于原安装目录 `backup`，需要回退时先退出新版，再恢复备份中的 `bin`。

## 互动

点击头部、身体可互动，长按头部可以提起并拖动。右键可选择休息、叫醒、走动、喂点心、喝茶、调整大小或安静陪伴。任务结束会挥手并提醒查看结果。状态条可查看本机 Codex 的工作状态、公开进展和额度。

角色尺寸在新版中独立保存。首次默认约 180 像素，也可从右键菜单调整。自主走动可暂停；收起后从系统托盘恢复。

## 角色与依赖

白龙动作素材由本项目以既有白龙形象为参考生成，原始动作图与导入脚本随源码保存。该运行包不含 VPet 默认角色及其动画。

动画内核使用 [VPet-Simulator.Core](https://github.com/LorisYounger/VPet)，保留相应开源许可和第三方组件声明。角色署名与内核来源可从右键“角色来源与关于”查看。

工作联动通过本机状态桥接完成，使用用户可见的工作状态、进展和明确的完成事件。运行包不包含本机设置、聊天记录或账户文件。
