# 更新记录

## v0.8.1 · 2026-10-30

从 v0.7.0 起累计加入以下能力：

- 六套白龙形态跟随当前轮模型和思考强度，Astra Ultra 使用神龙形态；长聊天重启后可恢复最新模型元数据。
- 33 个动作播放段使用连续时间与运动补帧；工作、睡眠、提起等保持姿态带局部连续动作。
- 图片在后台解码，缓存限制为近期动作；延迟时按经过时间取帧，新动作取消旧回调。
- 原生聊天客户端接入可选的本机小G服务，共享对话、记忆、养成和互动记录；回复表情受安静与减少动作设置控制。
- 增加待审提案与未读结果提示、逐条结果卡片和明确的查看入口。
- 右键菜单压缩为八个常用入口；气泡移到角色上方，长回复保留在聊天窗。
- 角色与状态条可按住移动，保留首段位移，松手落地，拖动不触发单击互动。
- 拖动中的完成提醒等待落地，收尾动作和庆祝各执行一次。

六档形态已逐档核对实际窗口渲染，包含快速切换。物理鼠标拖拽、多屏与跨 DPI 操作尚待手工验收。小G服务为可选依赖，公开包提供客户端和协议适配。

## v0.7.0 · 2026-10-26

- 保留既有白龙形象，接入 VPet-Simulator.Core 原生动画内核。
- 补制待机、摸头、提起、落地、走路、睡眠、唤醒、喝茶、点心、工作和挥手素材。
- 接入独立的本机 Codex 状态桥接，支持工作、完成提醒、额度与桥接恢复。
