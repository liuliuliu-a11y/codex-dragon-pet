# 参考与取舍

- [VPet](https://github.com/LorisYounger/VPet)：参考摸头、提起与气泡互动的产品思路。本项目保留自己的角色素材和独立实现。
- [Desktop Mate](https://store.steampowered.com/app/3301060/Desktop_Mate/)：参考工作期间轻量陪伴与鼠标互动的体验。
- [Shijima-Qt](https://github.com/pixelomer/Shijima-Qt)：调研过窗口交互与跨平台方案。该仓库已归档，本项目没有引入它作为依赖。
- [Microsoft WPF 动画性能](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/graphics-multimedia/animation-tips-and-tricks)：限制持续背景动画、隐藏时移除动画时钟。
- [Microsoft 分层窗口](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features#layered-windows)：鼠标穿透使用本窗口的透明扩展样式，托盘始终保留恢复互动入口。
- [Codex App Server](https://learn.chatgpt.com/docs/app-server)：账户额度采用 `account/rateLimits/read`。

角色为 ImageGen 生成的个人桌宠设计，视觉参考和提示词记录见 `assets/ART-NOTES.md`；不是 OpenAI 官方吉祥物。仓库不包含参考视频帧或第三方桌宠的原始动画。
